# AuthorizationProject — система авторизации пользователей

Учебный проект на **C++17**, демонстрирующий регистрацию и авторизацию пользователей, работу с базой данных SQLite, безопасное хранение паролей и создание простого локального HTTP-интерфейса.

## Возможности

- Регистрация пользователей и вход в систему.
- Хранение учётных записей в SQLite.
- Хеширование паролей с помощью PBKDF2-HMAC-SHA-256 и индивидуальной случайной соли.
- Использование подготовленных SQL-запросов.
- Консольный интерфейс и веб-интерфейс.
- Общий модуль авторизации для обеих версий приложения.
- Автоматическое создание базы данных при первом запуске.

## Используемые технологии

- **C++17** — основная логика приложения.
- **SQLite** — хранение учётных записей.
- **OpenSSL** — криптографические операции.
- **CMake** — сборка проекта.
- **HTML и CSS** — оформление веб-интерфейса.

## Зависимости (Arch Linux)

Установите необходимые пакеты:

```bash
sudo pacman -S --needed base-devel cmake sqlite openssl
```

## Сборка

Выполните команды из корня проекта:

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

### Консольная версия

```bash
./build/authorization
```

Выберите регистрацию, создайте пользователя, а затем проверьте вход в систему.

### Веб-версия

```bash
./build/authorization --web
```

Откройте в браузере:

http://127.0.0.1:8080

Для остановки сервера нажмите `Ctrl+C`.

## Правила регистрации

- **Логин:** от 3 до 32 символов; латинские буквы, цифры, `_` и `-`.
- **Пароль:** от 8 до 128 символов.
- Пароли хранятся в виде PBKDF2-хешей с индивидуальной случайной солью, а не в исходном виде.
- SQL-запросы выполняются с использованием подготовленных выражений.
- Консольная и веб-версии используют общий модуль авторизации и одну базу данных.

## Ограничения безопасности

Проект предназначен для обучения и демонстрации принципов авторизации. HTTP-сервер рассчитан на локальное использование и привязан к `127.0.0.1`.

**Не используйте проект для реальных аккаунтов и не открывайте его в публичный интернет.** Для production-приложения необходимы дополнительные меры защиты, включая HTTPS, CSRF-защиту, ограничение попыток входа, надёжное управление сессиями и использование проверенной HTTP-библиотеки.

## Цель проекта

Закрепить навыки разработки на C++, модульного проектирования, работы с SQLite, криптографического хеширования паролей и создания простых веб-приложений.
